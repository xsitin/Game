# WinForms → Godot: rewrite status

## Что переписано сейчас
- В `GodotClient` сделан отдельный клиент с новой UI-сценой на Godot Control API.
- Godot-клиент переключен на отдельный проект `Game.Core`.
- Локальные дубли боевой логики удалены из `GodotClient/scripts/Combat/*`: UI теперь использует только `Game.Core`.

## Новая архитектура (итеративная)
1. **Godot UI layer** (`Main.tscn` + `Main.cs`)
   - принимает ввод пользователя (Attack / Heal / Skip / Restart),
   - рендерит состояние и лог боя.
2. **Game.Core** (`Game.Core/Combat/*`)
   - хранит состояние команд,
   - выполняет правила урона/лечения,
   - управляет инициативной очередью (`TurnQueue`),
   - хранит переносимые примитивы старого домена (`Characteristic`, `BattleSkill`, `BattleBuff`, `BattleEffect`).
3. **Следующий шаг**
   - интегрировать новый генератор и persistence в экраны прогрессии/ростера (сейчас это подключено только к прототипному боевому экрану),
   - расширить migration path старых сейвов WinForms (добавлен базовый импорт уровней из legacy JSON, нужен импорт экономики/инвентаря).

## Что уже сближено с текущей WinForms-логикой
- Добавлены базовые автотесты `Game.Core.Tests` на детерминизм генератора энкаунтеров и валидацию skill-target API в `BattleEngine`.
- Добавлены параметры `PhysicalProtection`, `MagicalProtection`, `Evasion` в core-модель бойца.
- Физический урон в бою учитывает уклонение и защиту.
- Вынесена и подключена инициативная очередь хода (`TurnQueue`) вместо упрощенных локальных курсоров.
- Добавлен lifecycle бафов с тиками длительности и автоматическим снятием эффектов на истечении.
